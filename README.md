# Exodia Tower

Local-first AI command center with specialized assistants and an editorial workflow for YouTube, TikTok, and Instagram.

## Source of truth
This is the canonical repository. The previous Command Tower v0.2 package is a migration input, not the accepted user interface or an articulated character rig.

**Current state:** migration scaffold. Development occurs on feature branches and through pull requests. The initial migration is tracked under `development/exodia-foundation`.

## Quality gates
- Real rigged character performance: independent eyes, facial expressions, mouth, limbs, movement and interaction. Do not present parallax portraits as rigged animation.
- Modern desktop application; separate visual mockups from working functionality.
- Social publication requires platform authorization and explicit operator review; use official interfaces and never bypass posting limits.
- Local secrets and private data must never be committed.

See `docs/ROADMAP.md` on the development branch for checkpoints and migration steps.
