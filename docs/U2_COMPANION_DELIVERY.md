# U2 — Companion workstations and browser handoff

## Browser flow
1. In the new Command Center, start the three *visible* browser sessions and log in manually to each service. Session profiles persist under session_data/{chatgpt,gemini,deepseek}.
2. Choose a model, the responsible companion, and type the task. This creates a persisted draft.
3. Select Prepare, which fills the website input if the provider session is active; review and press Send on the website yourself.
4. Copy the output from the site and paste it into the companion's delivery panel. The result is stored locally and appears on the selected companion monitor.
5. If you generated an image, save it to your computer and attach a supported local image to that task. Its image is displayed on the companion monitor. It is **not** automatically fetched.

No step claims automated generation or extraction. Browser-only consumer subscriptions are not reliable substitutes for an authorized API. Headless mode cannot provide interactive login or copy-paste; use visible windows. Provider status such as needs_operator_login_or_review does not certify authentication.

## Security
Client is local-only; POST mutations use an operator dashboard marker that does not replace user authentication. Uploaded images are limited and served from local app_data/artifacts (ignored by git). Real account publishing and credentialed providers remain disconnected.
